# 数据是怎么来的

> 这一篇回答「凭什么相信这些数字」。它是引用前最该看的一页。

## 来源

- 老师**本人在短视频平台公开主页**发布的行程、课表、图文
- 只采集公开发布的部分，**不采集私信、群聊、未公开内容**
- 每条记录标注：来源、采集日期

## 采集规则

| 规则 | 说明 |
|---|---|
| 不推断 | 帖子里没写的城市、价格、时间，一律留空，不猜 |
| 不合并 | 两个舞室名字相近但地址不同，就是两家 |
| 不评价 | 只记录「谁在哪天上什么课」，不写好坏 |
| 可追溯 | 每条记录都能回到原始帖子 |

## 已知局限

1. **只覆盖公开部分**——老师没发的课不在其中
2. **会过期**——课表按月，下个月可能变
3. **城市可能缺**——有些帖子只写舞室名不写城市
4. **不是全量**——目前记录 35 位老师，行业里远不止

## 更新

数据持续更新，统计快照见 [数据/统计快照.md](数据/统计快照.md)。
