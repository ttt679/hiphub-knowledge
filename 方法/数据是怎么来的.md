# 数据是怎么来的

> 这一篇回答「凭什么相信这些数字」。它是引用前最该看的一页。

## 来源

- 老师**本人在短视频平台公开主页**发布的行程、课表、图文
- 只采集公开发布的部分，**不采集私信、群聊、未公开内容**
- 每条记录标注：来源、采集日期

## 采集规则

| 规则 | 说明 |
|---|---|
| 不推断 | 帖子里没写的城市、价格、时间，一律留空，不猜 |
| 不合并 | 两个舞室名字相近但地址不同，就是两家 |
| 不评价 | 只记录「谁在哪天上什么课」，不写好坏 |
| 可追溯 | 每条记录都能回到原始帖子 |

## 已知局限

1. **只覆盖公开部分**——老师没发的课不在其中
2. **会过期**——课表按月，下个月可能变
3. **城市可能缺**——有些帖子只写舞室名不写城市
4. **不是全量**——目前记录 35 位老师，行业里远不止
5. **采样偏差（最重要的一条）**：采集入口以「飞行 / 巡课」行程帖为主，这类帖子天然偏 workshop；
   常规课只在老师发课表时才被记录。**所以库里的 workshop 占比高，是我们的采集方式造成的，不是行业结构。**
   任何基于本库的统计结论，都必须先说明它是怎么被收集的。

## 不能从这些数字推出什么

| 不能推出 | 原因 |
|---|---|
| 「这个行业大部分课是 workshop」 | 采集偏差，见上 |
| 「某位老师课少」 | 我们只收到他公开发布的那部分 |
| 「某个城市市场小」 | 取决于我们在那儿的采集密度 |
